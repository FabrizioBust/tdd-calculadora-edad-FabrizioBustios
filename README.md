# TDD - Calculadora de edad

Proyecto inicial para desarrollar la actividad de Calidad y Pruebas de Software aplicando Red → Green → Refactor.

## Tecnología
- Java 21+
- Maven
- JUnit 5

## Ejecutar pruebas
```powershell
mvn test
```

La implementación y las pruebas se agregan progresivamente para conservar la evidencia real de cada ciclo TDD.
